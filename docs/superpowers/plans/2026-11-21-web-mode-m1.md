# Web Mode M1 Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** `crush --web` (or `/web`) opens a token-protected loopback browser tab that mirrors the running session live: holographic shell, transmission log, command deck, permission and question dialogs, synchronized both ways with the TUI.

**Architecture:** An in-process gateway (`internal/web`) wraps the same `workspace.Workspace` the TUI uses. It serves an embedded Vite build and exposes REST plus a WebSocket event stream. Events come from a new `Workspace.SubscribeEvents` and are encoded with the server's existing wire envelope, moved into a shared `internal/wire` package.

**Tech Stack:** Go 1.27, `net/http` mux patterns, `github.com/coder/websocket` (already a direct dependency), testify. Frontend: Vite, TypeScript, Preact + `@preact/signals`, Three.js, `marked` + `DOMPurify`, `@fontsource/*`, Vitest, Playwright.

**Spec:** `docs/superpowers/specs/2026-11-21-web-mode-design.md`. Executors read both documents. This plan covers milestone M1 only; M2 to M4 get their own plans.

## Global Constraints

- Listener binds `127.0.0.1:0` only; no option changes the address.
- Token: 32 bytes from `crypto/rand`, base64url (no padding); launch URL `http://127.0.0.1:<port>/#t=<token>`.
- Cookie: `crush_web=<token>; HttpOnly; SameSite=Strict; Path=/`.
- Every `/api/*` request and the WebSocket upgrade require a valid cookie (constant-time compare), allowed `Host` (`127.0.0.1:<port>` or `localhost:<port>`), and same-origin `Origin` when present. Every request, including static, requires an allowed `Host`.
- CSP: `default-src 'self'; img-src 'self' data: blob:; style-src 'self'; connect-src 'self'; object-src 'none'; frame-ancestors 'none'`, plus `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`.
- Stream: ring buffer 2048 frames; per-connection send queue 512, overflow closes with code 4001; client ping every 15 s; server idle close after 45 s.
- No business logic in the browser or gateway: every action is a `workspace.Workspace` call.
- `go build .` must work without Node: Vite builds straight into `internal/web/dist`, which is committed.
- Palette tokens, fonts and motion rules: spec section 3.1 and 3.4, copied verbatim into `web/src/styles/tokens.css` (Task 8).
- Go style: gofumpt, testify `require`, `t.Parallel()`, comments end with periods, log messages start with a capital letter, no em dashes in source.
- Read `internal/ui/AGENTS.md` before touching `internal/ui` (Task 13).

## Deviations from the spec (deliberate)

- Vite writes straight into `internal/web/dist` instead of building `web/dist` and copying it. One fewer step; same committed artifact.
- No `POST /api/follow`. Following the terminal is server-driven (`session_follow` frames); pinning another session is client state and lands with the session switcher in M3.
- The log windows to the last 200 messages with "Show earlier" in M1; true virtualization is deferred.

## Review Focus

1. A permission answered in the TUI while the browser dialog is open: the browser dialog closes with an "Answered in terminal" toast, and a late browser click returns `{"resolved": false}` rather than an error. Pinned in Task 5 (`TestGrantAlreadyResolved`) and Task 9 (`permission_notification removes pending and toasts`).
2. The tab stays open after crush exits or the socket drops for longer than the ring covers: the page shows "Session ended" or resyncs through a snapshot, never a blank screen or an error loop. Pinned in Task 4 (`TestStreamSinceTooOldGetsSnapshot`, `TestShutdownSendsClosing`) and Task 9 (`gateway_closing ends the connection`).
3. A request from another origin, or a DNS-rebinding `Host`, carrying a valid cookie is still rejected. Pinned in Task 3 (`TestAuthRejectsForeignOriginAndHost`).
4. A very long streaming answer (thousands of `message` updates) must not grow memory without bound or freeze the tab. Pinned in Task 4 (`TestRingIsBounded`, `TestSlowClientClosed4001`) and Task 9 (upsert by id, not append).
5. The terminal switches session while the tab is open: the tab follows, and messages from two sessions are never mixed. Pinned in Task 9 (`ignores messages for other sessions`, `session_follow resets messages`).

```go
// fanBuffer bounds each non-TUI subscriber; a full subscriber drops
// events and is expected to resync from a snapshot.
const fanBuffer = 512

func (w *ClientWorkspace) SubscribeEvents(ctx context.Context) <-chan any {
	ch := make(chan any, fanBuffer)
	w.fanMu.Lock()
	if w.fanSubs == nil {
		w.fanSubs = make(map[chan any]struct{})
	}
	w.fanSubs[ch] = struct{}{}
	w.fanMu.Unlock()
	go func() {
		<-ctx.Done()
		w.fanMu.Lock()
		delete(w.fanSubs, ch)
		close(ch)
		w.fanMu.Unlock()
	}()
	return ch
}

func (w *ClientWorkspace) broadcast(ev any) {
	w.fanMu.Lock()
	defer w.fanMu.Unlock()
	for ch := range w.fanSubs {

		}
	}
```

```go
		close(ch)
```

```go
package web

import (
	"crypto/rand"
	"crypto/subtle"
	"encoding/base64"
	"encoding/json"
	"net/http"
	"net/url"
	"strconv"
)

const cookieName = "crush_web"

const csp = "default-src 'self'; img-src 'self' data: blob:; style-src 'self'; " +
	"connect-src 'self'; object-src 'none'; frame-ancestors 'none'"

func newToken() (string, error) {
	b := make([]byte, 32)
	if _, err := rand.Read(b); err != nil {
		return "", err
	}
	return base64.RawURLEncoding.EncodeToString(b), nil
}

func (g *Gateway) hostAllowed(host string) bool {
	port := strconv.Itoa(g.port)
	return host == "127.0.0.1:"+port || host == "localhost:"+port
}

func (g *Gateway) originAllowed(r *http.Request) bool {
	origin := r.Header.Get("Origin")
	if origin == "" {
		return true
	}
	u, err := url.Parse(origin)
	if err != nil {
		return false
	}
	return u.Scheme == "http" && g.hostAllowed(u.Host) && u.Host == r.Host
}

func (g *Gateway) tokenMatches(candidate string) bool {
	return subtle.ConstantTimeCompare([]byte(candidate), []byte(g.secret)) == 1
}

// guard applies the host check and security headers to every request.
func (g *Gateway) guard(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		h := w.Header()
		h.Set("Content-Security-Policy", csp)
		h.Set("X-Content-Type-Options", "nosniff")
		h.Set("Referrer-Policy", "no-referrer")
		if !g.hostAllowed(r.Host) {
			http.Error(w, "forbidden host", http.StatusForbidden)
			return
		}
		next.ServeHTTP(w, r)
	})
}

// requireAuth protects API routes: same-origin and a valid cookie.
func (g *Gateway) requireAuth(next http.Handler) http.Handler {
	return http.HandlerFunc(func(w http.ResponseWriter, r *http.Request) {
		if !g.originAllowed(r) {
			writeError(w, http.StatusForbidden, "forbidden_origin", "cross-origin request rejected")
			return
		}
		c, err := r.Cookie(cookieName)
		if err != nil || !g.tokenMatches(c.Value) {
			writeError(w, http.StatusUnauthorized, "unauthorized", "missing or invalid session cookie")
			return
		}
		next.ServeHTTP(w, r)
	})
}

func (g *Gateway) handleAuth(w http.ResponseWriter, r *http.Request) {
	if !g.originAllowed(r) {
		writeError(w, http.StatusForbidden, "forbidden_origin", "cross-origin request rejected")
		return
	}
	var body struct {
		Token string `json:"token"`
	}
	if err := json.NewDecoder(http.MaxBytesReader(w, r.Body, 1024)).Decode(&body); err != nil || !g.tokenMatches(body.Token) {
		writeError(w, http.StatusUnauthorized, "unauthorized", "invalid token")
		return
	}
	http.SetCookie(w, &http.Cookie{
		Name:     cookieName,
		Value:    g.secret,
		Path:     "/",
		HttpOnly: true,
		SameSite: http.SameSiteStrictMode,
	})
	w.WriteHeader(http.StatusNoContent)
}

type apiError struct {
	Error string `json:"error"`
	Code  string `json:"code"`
}

func writeError(w http.ResponseWriter, status int, code, msg string) {
	writeJSON(w, status, apiError{Error: msg, Code: code})
}

func writeJSON(w http.ResponseWriter, status int, v any) {
	w.Header().Set("Content-Type", "application/json")
	w.WriteHeader(status)
	_ = json.NewEncoder(w).Encode(v)
}
```

```go
// Package web implements web mode: a loopback HTTP gateway that serves a
// browser UI mirroring one crush session.
package web

import (
	"context"
	"errors"
	"fmt"
	"io/fs"
	"log/slog"
	"net"
	"net/http"
	"time"

	"github.com/charmbracelet/crush/internal/workspace"
)

// Options configures a Gateway.
type Options struct {
	Workspace workspace.Workspace
	// Assets overrides the embedded frontend; nil uses the embedded dist.
	Assets fs.FS
}

// Gateway is a running web mode server bound to the loopback interface.
type Gateway struct {
	ws     workspace.Workspace
	secret string
	port   int
	ln     net.Listener
	srv    *http.Server
	ctx    context.Context
	cancel context.CancelFunc
	done   chan struct{}
}

// Start binds 127.0.0.1 on a random port and serves until Shutdown.
func Start(ctx context.Context, opts Options) (*Gateway, error) {
	if opts.Workspace == nil {
		return nil, errors.New("web: workspace is required")
	}
	secret, err := newToken()
	if err != nil {
		return nil, fmt.Errorf("web: generate token: %w", err)
	}
	ln, err := net.Listen("tcp", "127.0.0.1:0")
	if err != nil {
		return nil, fmt.Errorf("web: listen: %w", err)
	}
	assets := opts.Assets
	if assets == nil {
		assets = embeddedAssets()
	}
	gctx, cancel := context.WithCancel(context.WithoutCancel(ctx))
	g := &Gateway{
		ws:     opts.Workspace,
		secret: secret,
		port:   ln.Addr().(*net.TCPAddr).Port,
		ln:     ln,
		ctx:    gctx,
		cancel: cancel,
		done:   make(chan struct{}),
	}
	g.srv = &http.Server{
		Handler:           g.guard(g.routes(assets)),
		ReadHeaderTimeout: 10 * time.Second,
	}
	go func() {
		defer close(g.done)
		if err := g.srv.Serve(ln); err != nil && !errors.Is(err, http.ErrServerClosed) {
			slog.Error("Web gateway stopped", "error", err)
		}
	}()
	return g, nil
}

func (g *Gateway) routes(assets fs.FS) http.Handler {
	mux := http.NewServeMux()
	api := http.NewServeMux()
	api.HandleFunc("GET /api/health", func(w http.ResponseWriter, _ *http.Request) {
		writeJSON(w, http.StatusOK, map[string]bool{"ok": true})
	})
	mux.HandleFunc("POST /api/auth", g.handleAuth)
	mux.Handle("/api/", g.requireAuth(api))
	mux.Handle("/", assetHandler(assets))
	return mux
}

// URL returns the gateway origin, without the token.
func (g *Gateway) URL() string { return fmt.Sprintf("http://127.0.0.1:%d", g.port) }

// LaunchURL returns the URL that authenticates a browser tab. The token
// travels in the fragment so it never reaches server logs.
func (g *Gateway) LaunchURL() string { return g.URL() + "/#t=" + g.secret }

func (g *Gateway) token() string { return g.secret }

// Shutdown stops the gateway and closes every browser connection.
func (g *Gateway) Shutdown(ctx context.Context) error {
	g.cancel()
	err := g.srv.Shutdown(ctx)
	<-g.done
	return err
}
```

```go
package web

import (
	"encoding/json"

	"github.com/charmbracelet/crush/internal/proto"
	"github.com/charmbracelet/crush/internal/pubsub"
	"github.com/charmbracelet/crush/internal/wire"
	"github.com/charmbracelet/crush/internal/workspace"
)

// encode turns a workspace event into a frame type and its wire payload.
// Client/server mode delivers LSP events as workspace.LSPEvent, which the
// shared wire package does not know, so they are mapped here.
func encode(ev any) (string, json.RawMessage, bool) {
	if e, ok := ev.(pubsub.Event[workspace.LSPEvent]); ok {
		raw, err := json.Marshal(pubsub.Event[proto.LSPEvent]{
			Type: e.Type,
			Payload: proto.LSPEvent{
				Type:            proto.LSPEventType(e.Payload.Type),
				Name:            e.Payload.Name,
				State:           e.Payload.State,
				Error:           e.Payload.Error,
				DiagnosticCount: e.Payload.DiagnosticCount,
			},
		})
		if err != nil {
			return "", nil, false
		}
		return pubsub.PayloadTypeLSPEvent, raw, true
	}
	p := wire.Wrap(ev)
	if p == nil {
		return "", nil, false
	}
	return p.Type, p.Payload, true
}

// innerPayload returns only the entity of a wire event, so snapshot
// entries have exactly the shape of live event payloads.
func innerPayload(ev any) json.RawMessage {
	_, raw, ok := encode(ev)
	if !ok {
		return nil
	}
	var inner struct {
		Payload json.RawMessage `json:"payload"`
	}
	if err := json.Unmarshal(raw, &inner); err != nil {
		return nil
	}
	return inner.Payload
}
```

```go
package web

import (
	"sync"

	"github.com/charmbracelet/crush/internal/permission"
	"github.com/charmbracelet/crush/internal/pubsub"
	"github.com/charmbracelet/crush/internal/question"
)

// pending remembers unresolved prompts so the browser can answer by ID
// and so snapshots can restore open dialogs.
type pending struct {
	mu    sync.Mutex
	perms map[string]permission.PermissionRequest
	order []string
	q     *question.Request
}

func newPending() *pending {
	return &pending{perms: make(map[string]permission.PermissionRequest)}
}

func (p *pending) observe(ev any) {
	p.mu.Lock()
	defer p.mu.Unlock()
	switch e := ev.(type) {
	case pubsub.Event[permission.PermissionRequest]:
		if _, ok := p.perms[e.Payload.ID]; !ok {
			p.order = append(p.order, e.Payload.ID)
		}
		p.perms[e.Payload.ID] = e.Payload
	case pubsub.Event[permission.PermissionNotification]:
		for id, req := range p.perms {
			if req.ToolCallID == e.Payload.ToolCallID {
				delete(p.perms, id)
			}
		}
		p.compact()
	case pubsub.Event[question.Request]:
		q := e.Payload
		p.q = &q
	case pubsub.Event[question.Notification]:
		if p.q != nil && p.q.ID == e.Payload.BatchID {
			p.q = nil
		}
	}
}

func (p *pending) compact() {
	kept := p.order[:0]
	for _, id := range p.order {
		if _, ok := p.perms[id]; ok {
			kept = append(kept, id)
		}
	}
	p.order = kept
}

func (p *pending) permission(id string) (permission.PermissionRequest, bool) {
	p.mu.Lock()
	defer p.mu.Unlock()
	req, ok := p.perms[id]
	return req, ok
}

func (p *pending) permissions() []permission.PermissionRequest {
	p.mu.Lock()
	defer p.mu.Unlock()
	out := make([]permission.PermissionRequest, 0, len(p.order))
	for _, id := range p.order {
		out = append(out, p.perms[id])
	}
	return out
}

func (p *pending) question() *question.Request {
	p.mu.Lock()
	defer p.mu.Unlock()
	if p.q == nil {
		return nil
	}
	q := *p.q
	return &q
}

func (p *pending) forget(id string) {
	p.mu.Lock()
	delete(p.perms, id)
	p.compact()
	p.mu.Unlock()
}
```

```go
package web

import (
	"context"
	"encoding/json"
	"log/slog"
	"net/http"
	"strconv"
	"sync"
	"time"

	"github.com/coder/websocket"
)

const (
	ringSize      = 2048
	sendQueue     = 512
	idleTimeout   = 45 * time.Second
	writeTimeout  = 5 * time.Second
	closeResync   = websocket.StatusCode(4001)
	frameSnapshot = "snapshot"
	frameFollow   = "session_follow"
	frameClosing  = "gateway_closing"
	frameError    = "web_error"
)

type frame struct {
	Seq     uint64          `json:"seq"`
	Type    string          `json:"type"`
	Payload json.RawMessage `json:"payload"`
}

type conn struct {
	ch       chan frame
	overflow chan struct{}
	once     sync.Once
}

// hub sequences frames, keeps a bounded replay ring, and fans frames out
// to browser connections without ever blocking the publisher.
type hub struct {
	mu     sync.Mutex
	seq    uint64
	ring   []frame
	subs   map[*conn]struct{}
	closed bool
}

func newHub() *hub {
	return &hub{subs: make(map[*conn]struct{})}
}

func (h *hub) head() uint64 {
	h.mu.Lock()
	defer h.mu.Unlock()
	return h.seq
}

func (h *hub) publish(typ string, raw json.RawMessage) frame {
	h.mu.Lock()
	defer h.mu.Unlock()
	h.seq++
	f := frame{Seq: h.seq, Type: typ, Payload: raw}
	if len(h.ring) == ringSize {
		copy(h.ring, h.ring[1:])
		h.ring[ringSize-1] = f
	} else {
		h.ring = append(h.ring, f)
	}
	for c := range h.subs {
		select {
		case c.ch <- f:
		default:
			c.once.Do(func() { close(c.overflow) })
			delete(h.subs, c)
		}
	}
	return f
}

func (h *hub) publishJSON(typ string, v any) {
	raw, err := json.Marshal(v)
	if err != nil {
		slog.Error("Failed to marshal web frame", "type", typ, "error", err)
		return
	}
	h.publish(typ, raw)
}

// attach registers a connection. since < 0 asks for a snapshot. Replay and
// registration happen under one lock so no frame is lost or duplicated.
func (h *hub) attach(since int64) (*conn, []frame, bool, uint64) {
	h.mu.Lock()
	defer h.mu.Unlock()
	c := &conn{ch: make(chan frame, sendQueue), overflow: make(chan struct{})}
	if h.closed {
		close(c.ch)
		return c, nil, false, h.seq
	}
	h.subs[c] = struct{}{}
	if since < 0 || uint64(since) > h.seq {
		return c, nil, true, h.seq
	}
	if uint64(since) == h.seq {
		return c, nil, false, h.seq
	}
	if len(h.ring) == 0 || h.ring[0].Seq > uint64(since)+1 {
		return c, nil, true, h.seq
	}
	var replay []frame
	for _, f := range h.ring {
		if f.Seq > uint64(since) {
			replay = append(replay, f)
		}
	}
	return c, replay, false, h.seq
}

func (h *hub) detach(c *conn) {
	h.mu.Lock()
	defer h.mu.Unlock()
	if _, ok := h.subs[c]; ok {
		delete(h.subs, c)
		close(c.ch)
	}
}

// close ends every connection after its queued frames are written.
func (h *hub) close() {
	h.mu.Lock()
	defer h.mu.Unlock()
	h.closed = true
	for c := range h.subs {
		delete(h.subs, c)
		close(c.ch)
	}
}

func (g *Gateway) handleStream(w http.ResponseWriter, r *http.Request) {
	since := int64(-1)
	if s := r.URL.Query().Get("since"); s != "" {
		if n, err := strconv.ParseInt(s, 10, 64); err == nil && n >= 0 {
			since = n
		}
	}
	ws, err := websocket.Accept(w, r, nil)
	if err != nil {
		return
	}
	defer ws.CloseNow()

	ctx, cancel := context.WithCancel(r.Context())
	defer cancel()
	c, replay, needSnapshot, head := g.hub.attach(since)
	defer g.hub.detach(c)

	go g.readLoop(ctx, cancel, ws)

	if needSnapshot {
		raw, err := json.Marshal(g.buildSnapshot(ctx, g.ws.CurrentSessionID()))
		if err != nil {
			return
		}
		if !writeFrame(ctx, ws, frame{Seq: head, Type: frameSnapshot, Payload: raw}) {
			return
		}
	}
	for _, f := range replay {
		if !writeFrame(ctx, ws, f) {
			return
		}
	}
	for {
		select {
		case f, ok := <-c.ch:
			if !ok {
				ws.Close(websocket.StatusGoingAway, "gateway closing")
				return
			}
			if !writeFrame(ctx, ws, f) {
				return
			}
		case <-c.overflow:
			ws.Close(closeResync, "resync")
			return
		case <-ctx.Done():
			return
		}
	}
}

// readLoop consumes client pings and cancels the connection when the
// client goes quiet for idleTimeout.
func (g *Gateway) readLoop(ctx context.Context, cancel context.CancelFunc, ws *websocket.Conn) {
	defer cancel()
	for {
		rctx, rcancel := context.WithTimeout(ctx, idleTimeout)
		_, _, err := ws.Read(rctx)
		rcancel()
		if err != nil {
			return
		}
	}
}

func writeFrame(ctx context.Context, ws *websocket.Conn, f frame) bool {
	data, err := json.Marshal(f)
	if err != nil {
		return false
	}
	wctx, cancel := context.WithTimeout(ctx, writeTimeout)
	defer cancel()
	return ws.Write(wctx, websocket.MessageText, data) == nil
}
```

```go
		s.Session = innerPayload(pubsub.Event[session.Session]{Type: pubsub.UpdatedEvent, Payload: sess})
```

```go
// followInterval is how often the gateway checks which session the
// terminal is viewing. Polling keeps the TUI free of web-specific hooks.
const followInterval = 250 * time.Millisecond

func (g *Gateway) pump() {
	events := g.ws.SubscribeEvents(g.ctx)
	ticker := time.NewTicker(followInterval)
	defer ticker.Stop()
	last := g.ws.CurrentSessionID()
	for {
		select {
		case <-g.ctx.Done():
			return
		case ev, ok := <-events:
			if !ok {
				return
			}
			g.pending.observe(ev)
			if typ, raw, ok := encode(ev); ok {
				g.hub.publish(typ, raw)
			}
		case <-ticker.C:
			if cur := g.ws.CurrentSessionID(); cur != last {
				last = cur
				g.hub.publishJSON(frameFollow, map[string]string{"session_id": cur})
			}
		}
	}
}
```

```go
func decodeJSON(w http.ResponseWriter, r *http.Request, v any) bool {
	if err := json.NewDecoder(http.MaxBytesReader(w, r.Body, maxJSONBytes)).Decode(v); err != nil && !errors.Is(err, io.EOF) {
		writeError(w, http.StatusBadRequest, "bad_json", "request body is not valid JSON")
		return false
	}
	return true
}

// handlePrompt starts a run detached from the HTTP request, the same way
// the TUI runs prompts in a background command. Failures reach the tab as
// a web_error frame.
func (g *Gateway) handlePrompt(w http.ResponseWriter, r *http.Request) {
	sid := r.PathValue("sid")
	r.Body = http.MaxBytesReader(w, r.Body, maxPromptBytes)
	if err := r.ParseMultipartForm(maxPromptBytes); err != nil {
		writeError(w, http.StatusBadRequest, "bad_form", "prompt must be multipart form data under 32 MiB")
		return
	}
	prompt := r.FormValue("prompt")
	if strings.TrimSpace(prompt) == "" {
		writeError(w, http.StatusBadRequest, "empty_prompt", "prompt is empty")
		return
	}
	var atts []message.Attachment
	for _, fh := range r.MultipartForm.File["attachments"] {
		f, err := fh.Open()
		if err != nil {
			writeError(w, http.StatusBadRequest, "bad_attachment", err.Error())
			return
		}
		data, err := io.ReadAll(f)
		f.Close()
		if err != nil {
			writeError(w, http.StatusBadRequest, "bad_attachment", err.Error())
			return
		}
		atts = append(atts, message.Attachment{
			FileName: filepath.Base(fh.Filename),
			MimeType: attachmentMime(fh.Filename, data),
			Content:  data,
		})
	}
	ctx := context.WithoutCancel(g.ctx)
	go func() {
		if err := g.ws.AgentRun(ctx, sid, prompt, atts...); err != nil {
			slog.Warn("Web prompt failed", "session_id", sid, "error", err)
			g.hub.publishJSON(frameError, map[string]string{"session_id": sid, "error": err.Error()})
		}
	}()
	writeJSON(w, http.StatusAccepted, map[string]bool{"accepted": true})
}

func attachmentMime(name string, data []byte) string {
	if t := mime.TypeByExtension(strings.ToLower(filepath.Ext(name))); t != "" {
		return strings.Split(t, ";")[0]
	}
	return strings.Split(http.DetectContentType(data), ";")[0]
}

func (g *Gateway) handleGrant(w http.ResponseWriter, r *http.Request) {
	var body struct {
		ID     string `json:"id"`
		Action string `json:"action"`
	}
	if !decodeJSON(w, r, &body) {
		return
	}
	req, ok := g.pending.permission(body.ID)
	if !ok {
		writeError(w, http.StatusNotFound, "not_pending", "permission request is no longer pending")
		return
	}
	var resolved bool
	switch body.Action {
	case "allow":
		resolved = g.ws.PermissionGrant(req)
	case "allow_session":
		resolved = g.ws.PermissionGrantPersistent(req)
	case "deny":
		resolved = g.ws.PermissionDeny(req)
	default:
		writeError(w, http.StatusBadRequest, "bad_action", "action must be allow, allow_session or deny")
		return
	}
	if resolved {
		g.pending.forget(body.ID)
	}
	writeJSON(w, http.StatusOK, map[string]bool{"resolved": resolved})
}
```

```go
package web

import (
	"context"
	"fmt"
	"log/slog"
	"sync"

	"github.com/charmbracelet/crush/internal/browser"
	"github.com/charmbracelet/crush/internal/workspace"
)

// Controller owns the lifetime of one process's gateway. It starts the
// gateway lazily, so the TUI pays nothing until web mode is requested.
type Controller struct {
	ws   workspace.Workspace
	open func(string) error

	mu sync.Mutex
	gw *Gateway
}

// NewController returns a controller for ws that opens tabs with the
// system browser.
func NewController(ws workspace.Workspace) *Controller {
	return &Controller{ws: ws, open: browser.OpenURL}
}

// Start runs the gateway if needed and returns the launch URL.
func (c *Controller) Start(ctx context.Context) (string, error) {
	c.mu.Lock()
	defer c.mu.Unlock()
	if c.gw == nil {
		gw, err := Start(ctx, Options{Workspace: c.ws})
		if err != nil {
			return "", err
		}
		c.gw = gw
		slog.Info("Web mode started", "url", gw.URL())
	}
	return c.gw.LaunchURL(), nil
}

// Open starts the gateway if needed and opens a browser tab. When the
// browser cannot be opened the URL is still returned so the caller can
// show it.
func (c *Controller) Open(ctx context.Context) (string, error) {
	u, err := c.Start(ctx)
	if err != nil {
		return "", err
	}
	if err := c.open(u); err != nil {
		return u, fmt.Errorf("open browser: %w", err)
	}
	return u, nil
}

// Running reports whether the gateway is serving.
func (c *Controller) Running() bool {
	c.mu.Lock()
	defer c.mu.Unlock()
	return c.gw != nil
}

// Shutdown stops the gateway if it runs.
func (c *Controller) Shutdown(ctx context.Context) error {
	c.mu.Lock()
	gw := c.gw
	c.gw = nil
	c.mu.Unlock()
	if gw == nil {
		return nil
	}
	return gw.Shutdown(ctx)
}
```

```go
import (
	"context"
	"strings"
	"time"

	"github.com/charmbracelet/crush/internal/message"
	"github.com/charmbracelet/crush/internal/permission"
	"github.com/charmbracelet/crush/internal/pubsub"

	"github.com/charmbracelet/crush/internal/session"

// Scripted returns an AgentRun implementation that plays a short, fixed
// conversation. Prompts containing "permission" raise a permission
// request; prompts containing "question" raise a question batch.
func Scripted(f *Fake) func(ctx context.Context, sid, prompt string, att []message.Attachment) error {
	return func(ctx context.Context, sid, prompt string, _ []message.Attachment) error {
		now := time.Now().Unix()
		user := message.Message{ID: f.nextID("u"), SessionID: sid, Role: message.User, CreatedAt: now, UpdatedAt: now,
			Parts: []message.ContentPart{message.TextContent{Text: prompt}}}
		f.AddMessage(user)
		f.Emit(pubsub.Event[message.Message]{Type: pubsub.CreatedEvent, Payload: user})

		asst := message.Message{ID: f.nextID("a"), SessionID: sid, Role: message.Assistant, CreatedAt: now + 1, UpdatedAt: now + 1}
		emit := func(parts ...message.ContentPart) {
			asst.Parts = parts
			f.Emit(pubsub.Event[message.Message]{Type: pubsub.UpdatedEvent, Payload: asst})
		}
		thinking := message.ReasoningContent{Thinking: "Mapping the request onto the workspace."}
		emit(thinking)
		for _, chunk := range []string{"Signal ", "Signal received. ", "Signal received. " + prompt} {
			select {
			case <-ctx.Done():
				return ctx.Err()
			case <-time.After(60 * time.Millisecond):
			}
			emit(thinking, message.TextContent{Text: chunk})
		}
		text := "Signal received. " + prompt
		switch {
		case strings.Contains(prompt, "permission"):
			call := message.ToolCall{ID: f.nextID("tc"), Name: "bash", Input: `{"command":"go test ./..."}`}
			emit(thinking, message.TextContent{Text: text}, call)
			req := permission.PermissionRequest{ID: f.nextID("perm"), SessionID: sid, ToolCallID: call.ID, ToolName: "bash",
				Description: "Run the test suite", Action: "execute", Params: map[string]string{"command": "go test ./..."}, Path: f.WorkingDir()}
			f.Emit(pubsub.Event[permission.PermissionRequest]{Type: pubsub.CreatedEvent, Payload: req})
			select {
			case <-ctx.Done():
				return ctx.Err()
			case n := <-f.decisions:
				if n.Granted {
					text += "\n\nPermission granted, continuing."
				} else {
					text += "\n\nPermission denied, stopping."
				}
			}
		case strings.Contains(prompt, "question"):
			q := question.Request{ID: f.nextID("q"), SessionID: sid, ToolCallID: f.nextID("tc"), Questions: []question.Question{{
				ID: "flavor", Type: question.TypeSingleChoice, Text: "Which theme should the hologram use?",
				Description: "Pick one; the agent continues with your choice.",
				Choices:     []question.Choice{{ID: "cyan", Label: "Cyan"}, {ID: "magenta", Label: "Magenta"}},
			}}}
			f.Emit(pubsub.Event[question.Request]{Type: pubsub.CreatedEvent, Payload: q})
			select {
			case <-ctx.Done():
				return ctx.Err()
			case a := <-f.answers:
				f.Emit(pubsub.Event[question.Notification]{Type: pubsub.UpdatedEvent, Payload: question.Notification{BatchID: q.ID, SessionID: sid}})
				choice := ""
				if len(a) > 0 && len(a[0].SelectedIDs) > 0 {
					choice = a[0].SelectedIDs[0]
				}
				text += "\n\nYou chose " + choice + "."
			}
		}
		final := message.Finish{Reason: message.FinishReasonEndTurn, Time: time.Now().Unix()}
		emit(thinking, message.TextContent{Text: text}, final)
		f.AddMessage(asst)
		f.Emit(pubsub.Event[session.Session]{Type: pubsub.UpdatedEvent, Payload: session.Session{
			ID: sid, Title: "Holodeck test", PromptTokens: 1200, CompletionTokens: 340, Cost: 0.0123,
		}})
		return nil
	}
}
```

```go
// Regenerate with CRUSH_WEB_FIXTURES=1 go test ./internal/web -run TestWireFixtures.
func TestWireFixtures(t *testing.T) {
	t.Parallel()
	out := map[string]frame{}
	for name, ev := range fixtureEvents() {
		typ, raw, ok := encode(ev)
		require.True(t, ok, name)
		out[name] = frame{Seq: 1, Type: typ, Payload: raw}
	}
	got, err := json.MarshalIndent(out, "", "  ")
	require.NoError(t, err)
	got = append(got, '\n')

	if os.Getenv("CRUSH_WEB_FIXTURES") == "1" {
		require.NoError(t, os.MkdirAll(filepath.Dir(fixturePath), 0o755))
		require.NoError(t, os.WriteFile(fixturePath, got, 0o644))
		return
	}
	want, err := os.ReadFile(fixturePath)
	if errors.Is(err, os.ErrNotExist) {
		t.Fatalf("missing %s; run with CRUSH_WEB_FIXTURES=1", fixturePath)
	}
	require.NoError(t, err)
	require.JSONEq(t, string(want), string(got))
}
```

```ts
import type {
  Frame, Message, ModelInfo, PermissionMode, PermissionNotification, PermissionRequest,
  QuestionRequest, Session, Snapshot, ToolResultData, WireEvent,
} from '../api/types';

export type Conn = 'booting' | 'live' | 'reconnecting' | 'ended' | 'unauthorized';
export type Tone = 'info' | 'success' | 'warn' | 'error';
export interface Toast { id: number; tone: Tone; text: string }
export interface ServerState { state: string; diagnostics: number }

export interface State {
  conn: Conn;
  lastSeq: number;
  version: string;
  workingDir: string;
  project: string;
  branch: string;
  model: ModelInfo;
  permissionMode: PermissionMode;
  sessionId: string;
  session: Session | null;
  messages: Message[];
  permissions: PermissionRequest[];
  question: QuestionRequest | null;
  busy: boolean;
  queued: string[];
  toasts: Toast[];
  nextToastId: number;
  answered: string[];
  lsp: Record<string, ServerState>;
  needsReload: string | null;
}

export function initialState(): State {
  return {
    conn: 'booting', lastSeq: 0, version: '', workingDir: '', project: '', branch: '',
    model: { id: '', name: '', provider: '', context_window: 0 },
    permissionMode: 'normal', sessionId: '', session: null, messages: [],
    permissions: [], question: null, busy: false, queued: [], toasts: [],
    nextToastId: 1, answered: [], lsp: {}, needsReload: null,
  };
}

const MAX_TOASTS = 4;

export function pushToast(s: State, tone: Tone, text: string): State {
  const toasts = [...s.toasts, { id: s.nextToastId, tone, text }].slice(-MAX_TOASTS);
  return { ...s, toasts, nextToastId: s.nextToastId + 1 };
}

export function dismissToast(s: State, id: number): State {
  return { ...s, toasts: s.toasts.filter((t) => t.id !== id) };
}

export function setConn(s: State, conn: Conn): State {
  return s.conn === conn ? s : { ...s, conn };
}

export function markAnswered(s: State, id: string): State {
  return { ...s, answered: [...s.answered, id] };
}

export function adoptSession(s: State, id: string): State {
  return { ...s, sessionId: id, session: null, messages: [], busy: false, needsReload: id };
}

export function contextFill(s: State): number {
  const win = s.model.context_window;
  if (!s.session || win <= 0) return 0;
  return Math.min(1, (s.session.prompt_tokens + s.session.completion_tokens) / win);
}

export function toolResults(messages: Message[]): Map<string, ToolResultData> {
  const out = new Map<string, ToolResultData>();
  for (const m of messages) {
    for (const p of m.parts) if (p.type === 'tool_result') out.set(p.data.tool_call_id, p.data);
  }
  return out;
}

function projectName(dir: string): string {
  const parts = dir.split(/[\\/]/).filter(Boolean);
  return parts.at(-1) ?? dir;
}

function isOpenAssistant(m: Message): boolean {
  return m.role === 'assistant' && !m.parts.some((p) => p.type === 'finish');
}

function upsert(list: Message[], m: Message): Message[] {
  const i = list.findIndex((x) => x.id === m.id);
  if (i >= 0) {
    const next = list.slice();
    next[i] = m;
    return next;
  }
  const next = [...list, m];
  if (list.length && list[list.length - 1].created_at > m.created_at) {
    next.sort((a, b) => a.created_at - b.created_at);
  }
  return next;
}

function applySnapshot(s: State, seq: number, snap: Snapshot): State {
  const messages = snap.messages ?? [];
  const last = messages.at(-1);
  return {
    ...s,
    conn: 'live',
    lastSeq: seq,
    version: snap.version,
    workingDir: snap.working_dir,
    project: projectName(snap.working_dir),
    branch: snap.branch ?? '',
    model: snap.model,
    permissionMode: snap.permission_mode,
    sessionId: snap.current_session_id,
    session: snap.session ?? null,
    messages,
    permissions: snap.permissions ?? [],
    question: snap.question ?? null,
    busy: snap.busy || (last ? isOpenAssistant(last) : false),
    queued: snap.queued ?? [],
    needsReload: null,
  };
}

export function reduce(s: State, f: Frame): State {
  const next = { ...s, lastSeq: Math.max(s.lastSeq, f.seq) };
  const ev = f.payload as WireEvent<any>;
  switch (f.type) {
    case 'snapshot':
      return applySnapshot(s, f.seq, f.payload as Snapshot);
    case 'session_follow': {
      const id = (f.payload as { session_id: string }).session_id;
      return id === s.sessionId ? next : { ...adoptSession(next, id), needsReload: id || null };
    }
    case 'gateway_closing':
      return { ...next, conn: 'ended', busy: false };
    case 'web_error':
      return pushToast(next, 'error', (f.payload as { error: string }).error);
    case 'message': {
      const m = ev.payload as Message;
      if (m.session_id !== s.sessionId) return next;
      if (ev.type === 'deleted') return { ...next, messages: s.messages.filter((x) => x.id !== m.id) };
      const messages = upsert(s.messages, m);
      const busy = m.role === 'assistant' ? isOpenAssistant(m) : s.busy || m.role === 'user';
      return { ...next, messages, busy };
    }
    case 'session': {
      const sess = ev.payload as Session;
      if (sess.id !== s.sessionId) return next;
      return { ...next, session: sess, busy: sess.is_busy || s.busy };
    }
    case 'run_complete': {
      const rc = ev.payload as { session_id: string };
      return rc.session_id === s.sessionId ? { ...next, busy: false } : next;
    }
    case 'permission_request': {
      const req = ev.payload as PermissionRequest;
      if (s.permissions.some((p) => p.id === req.id)) return next;
      return { ...next, permissions: [...s.permissions, req] };
    }
    case 'permission_notification': {
      const n = ev.payload as PermissionNotification;
      const gone = s.permissions.filter((p) => p.tool_call_id === n.tool_call_id);
      if (!gone.length) return next;
      const out = { ...next, permissions: s.permissions.filter((p) => p.tool_call_id !== n.tool_call_id) };
      const local = gone.some((p) => s.answered.includes(p.id));
      return local || n.cancelled ? out : pushToast(out, 'info', 'Permission answered in the terminal');
    }
    case 'question_batch_request':
      return { ...next, question: ev.payload as QuestionRequest };
    case 'question_batch_notification': {
      const n = ev.payload as { batch_id: string };
      if (!s.question || s.question.id !== n.batch_id) return next;
      const out = { ...next, question: null };
      return s.answered.includes(n.batch_id) ? out : pushToast(out, 'info', 'Question answered in the terminal');
    }
    case 'permission_mode_changed':
      return { ...next, permissionMode: (ev.payload as { mode: PermissionMode }).mode };
    case 'lsp_event': {
      const e = ev.payload as { name: string; state: string; diagnostic_count?: number };
      return { ...next, lsp: { ...s.lsp, [e.name]: { state: String(e.state), diagnostics: e.diagnostic_count ?? 0 } } };
    }
    default:
      return next;
  }
}
```

```ts
import type { PermissionMode, QuestionAnswer, Snapshot, Session, Message } from './types';

export class ApiError extends Error {
  constructor(public status: number, public code: string, message: string) { super(message); }
}

async function call<T>(method: string, path: string, body?: unknown): Promise<T> {
  const init: RequestInit = { method, credentials: 'same-origin', headers: {} };
  if (body instanceof FormData) init.body = body;
  else if (body !== undefined) {
    init.body = JSON.stringify(body);
    (init.headers as Record<string, string>)['Content-Type'] = 'application/json';
  }
  const rsp = await fetch(path, init);
  if (rsp.status === 204) return undefined as T;
  const data = await rsp.json().catch(() => ({}));
  if (!rsp.ok) throw new ApiError(rsp.status, data.code ?? 'http_error', data.error ?? rsp.statusText);
  return data as T;
}

export type GrantAction = 'allow' | 'allow_session' | 'deny';

export const api = {
  auth: (token: string) => call<void>('POST', '/api/auth', { token }),
  async health(): Promise<'ok' | 'unauthorized' | 'down'> {
    try {
      const rsp = await fetch('/api/health', { credentials: 'same-origin' });
      if (rsp.status === 401) return 'unauthorized';
      return rsp.ok ? 'ok' : 'down';
    } catch {
      return 'down';
    }
  },
  snapshot: (sid?: string) => call<Snapshot>('GET', `/api/snapshot${sid ? `?session=${encodeURIComponent(sid)}` : ''}`),
  createSession: (title: string) => call<Session>('POST', '/api/sessions', { title }),
  messages: (sid: string) => call<Message[]>('GET', `/api/sessions/${encodeURIComponent(sid)}/messages`),
  sendPrompt(sid: string, prompt: string, files: File[]) {
    const form = new FormData();
    form.set('prompt', prompt);
    for (const f of files) form.append('attachments', f, f.name);
    return call<{ accepted: boolean }>('POST', `/api/sessions/${encodeURIComponent(sid)}/prompt`, form);
  },
  cancel: (sid: string) => call<void>('POST', `/api/sessions/${encodeURIComponent(sid)}/cancel`),
  clearQueue: (sid: string) => call<void>('DELETE', `/api/sessions/${encodeURIComponent(sid)}/queue`),
  grant: (id: string, action: GrantAction) => call<{ resolved: boolean }>('POST', '/api/permissions/grant', { id, action }),
  setMode: (mode: PermissionMode) => call<void>('POST', '/api/permissions/mode', { mode }),
  answer: (answers: QuestionAnswer[]) => call<{ resolved: boolean }>('POST', '/api/questions/answer', { answers }),
  cancelQuestion: () => call<{ resolved: boolean }>('POST', '/api/questions/cancel'),
  completeFiles: (q: string) => call<{ files: string[]; truncated: boolean }>('GET', `/api/complete/files?q=${encodeURIComponent(q)}`),
```

```ts
import { api } from './http';

export interface StreamHandlers {
  onFrames(frames: Frame[]): void;
  onConn(c: Conn): void;
  lastSeq(): number;
}

type SocketLike = {
  onopen?: (() => void) | null;
  onmessage?: ((e: { data: string }) => void) | null;
  onclose?: ((e: { code: number }) => void) | null;
  send(d: string): void;
  close(code?: number): void;
};

export interface StreamEnv {
  url(since: number): string;
  WebSocket: new (url: string) => SocketLike;
  health(): Promise<'ok' | 'unauthorized' | 'down'>;
  schedule(fn: () => void): void;
  setTimeout(fn: () => void, ms: number): unknown;
  setInterval(fn: () => void, ms: number): unknown;
  clearInterval(id: unknown): void;
}

const PING_MS = 15_000;
const MAX_DOWN = 5;
const CLOSE_RESYNC = 4001;

export function browserEnv(): StreamEnv {
  const proto = location.protocol === 'https:' ? 'wss' : 'ws';
  return {
    url: (since) => `${proto}://${location.host}/api/stream${since > 0 ? `?since=${since}` : ''}`,
    WebSocket: WebSocket as unknown as StreamEnv['WebSocket'],
    health: () => api.health(),
    schedule: (fn) => requestAnimationFrame(() => fn()),
    setTimeout: (fn, ms) => window.setTimeout(fn, ms),
    setInterval: (fn, ms) => window.setInterval(fn, ms),
    clearInterval: (id) => window.clearInterval(id as number),
  };
}

// connectStream keeps one WebSocket alive, batching frames per animation
// frame so streaming deltas cost one render each, and resumes with
// ?since=<seq> after a drop. Returns a function that stops it.
export function connectStream(h: StreamHandlers, env: StreamEnv = browserEnv()): () => void {
  let stopped = false;
  let ended = false;
  let down = 0;
  let attempt = 0;
  let resync = false;
  let buffer: Frame[] = [];
  let scheduled = false;
  let ping: unknown = null;

  const flush = () => {
    scheduled = false;
    const batch = buffer;
    buffer = [];
    if (batch.length) h.onFrames(batch);
  };

  const retry = () => {
    if (stopped || ended) return;
    h.onConn('reconnecting');
    const delay = Math.min(10_000, 500 * 2 ** attempt++);
    env.setTimeout(() => void open(), delay);
  };

  const open = async () => {
    if (stopped) return;
    const status = await env.health();
    if (status === 'unauthorized') { h.onConn('unauthorized'); return; }
    if (status === 'down') {
      if (++down >= MAX_DOWN) { ended = true; h.onConn('ended'); return; }
      retry();
      return;
    }
    down = 0;
    const since = resync ? 0 : h.lastSeq();
    resync = false;
    const ws = new env.WebSocket(env.url(since));
    ws.onopen = () => {
      attempt = 0;
      ping = env.setInterval(() => ws.send('{"type":"ping"}'), PING_MS);
    };
    ws.onmessage = (e) => {
      const f = JSON.parse(e.data) as Frame;
      if (f.type === 'gateway_closing') ended = true;
      buffer.push(f);
      if (!scheduled) { scheduled = true; env.schedule(flush); }
    };
    ws.onclose = (e) => {
      if (ping !== null) env.clearInterval(ping);
      flush();
      if (ended) { h.onConn('ended'); return; }
      if (e.code === CLOSE_RESYNC) resync = true;
      retry();
    };
  };

  void open();
  return () => { stopped = true; };
}
```

```ts
import { signal } from '@preact/signals';
import { api, ApiError, type GrantAction } from '../api/http';
import { connectStream } from '../api/stream';
import type { PermissionMode, QuestionAnswer, Snapshot } from '../api/types';
import {
  adoptSession, dismissToast, initialState, markAnswered, pushToast, reduce, setConn, type State,
} from './reducer';

export const state = signal<State>(initialState());

export function dispatch(fn: (s: State) => State) {
  state.value = fn(state.value);
}

function errorText(err: unknown): string {
  return err instanceof ApiError ? err.message : 'The request did not reach crush';
}

async function reloadSession(id: string) {
  try {
    const snap: Snapshot = await api.snapshot(id);
    dispatch((s) => (s.sessionId === id ? reduce(s, { seq: s.lastSeq, type: 'snapshot', payload: snap }) : s));
  } catch (err) {
    dispatch((s) => pushToast(s, 'error', `Could not load the session: ${errorText(err)}`));
  }
}

export async function boot() {
  const token = new URLSearchParams(location.hash.slice(1)).get('t');
  if (token) {
    await api.auth(token).catch(() => undefined);
    history.replaceState(null, '', location.pathname);
  }
  connectStream({
    onFrames: (frames) => {
      dispatch((s) => frames.reduce(reduce, s));
      const id = state.value.needsReload;
      if (id) {
        dispatch((s) => ({ ...s, needsReload: null }));
        void reloadSession(id);
      }
    },
    onConn: (c) => dispatch((s) => setConn(s, c)),
    lastSeq: () => state.value.lastSeq,
  });
}

export const actions = {
  async sendPrompt(prompt: string, files: File[]): Promise<boolean> {
    let sid = state.value.sessionId;
    try {
      if (!sid) {
        const created = await api.createSession(prompt.slice(0, 60));
        sid = created.id;
        dispatch((s) => adoptSession(s, sid));
      }
      await api.sendPrompt(sid, prompt, files);
      return true;
    } catch (err) {
      dispatch((s) => pushToast(s, 'error', `Prompt not sent: ${errorText(err)}`));
      return false;
    }
  },
  async cancel() {
    const sid = state.value.sessionId;
    if (sid) await api.cancel(sid).catch((err) => dispatch((s) => pushToast(s, 'error', errorText(err))));
  },
  async clearQueue() {
    const sid = state.value.sessionId;
    if (sid) await api.clearQueue(sid).catch((err) => dispatch((s) => pushToast(s, 'error', errorText(err))));
  },
  async grant(id: string, action: GrantAction) {
    dispatch((s) => markAnswered(s, id));
    try {
      const { resolved } = await api.grant(id, action);
      if (!resolved) dispatch((s) => pushToast(s, 'info', 'Already answered in the terminal'));
    } catch (err) {
      if (err instanceof ApiError && err.code === 'not_pending') {
        dispatch((s) => ({ ...pushToast(s, 'info', 'Already answered in the terminal'), permissions: s.permissions.filter((p) => p.id !== id) }));
      } else {
        dispatch((s) => pushToast(s, 'error', errorText(err)));
      }
    }
  },
  async setMode(mode: PermissionMode) {
    await api.setMode(mode).catch((err) => dispatch((s) => pushToast(s, 'error', errorText(err))));
  },
  async answer(batchId: string, answers: QuestionAnswer[]) {
    dispatch((s) => markAnswered(s, batchId));
    try {
      const { resolved } = await api.answer(answers);
      if (!resolved) dispatch((s) => pushToast(s, 'info', 'Already answered in the terminal'));
    } catch (err) {
      dispatch((s) => pushToast(s, 'error', errorText(err)));
    }
  },
  async cancelQuestion(batchId: string) {
    dispatch((s) => markAnswered(s, batchId));
    await api.cancelQuestion().catch((err) => dispatch((s) => pushToast(s, 'error', errorText(err))));
  },
  dismissToast: (id: number) => dispatch((s) => dismissToast(s, id)),
};
```

```ts
// Each crush terminal gets its own tab; a stable per-project hue on the
// favicon tells them apart at a glance.
export function projectHue(dir: string): number {
  let h = 2166136261;
  for (let i = 0; i < dir.length; i++) {
    h ^= dir.charCodeAt(i);
    h = Math.imul(h, 16777619);
  }
  return (h >>> 0) % 360;
}

export function faviconFor(hue: number): string {
  const c = `hsl(${hue} 90% 65%)`;
  const svg = `<svg xmlns="http://www.w3.org/2000/svg" viewBox="0 0 32 32"><polygon points="16,2 28,9 28,23 16,30 4,23 4,9" fill="none" stroke="${c}" stroke-width="2.5"/><circle cx="16" cy="16" r="5" fill="${c}"/></svg>`;
  return `data:image/svg+xml,${encodeURIComponent(svg)}`;
}

export function tabTitle(project: string, sessionTitle: string, attention: boolean): string {
  const base = `${project} · ${sessionTitle || 'New session'}`;
  return attention ? `(!) ${base}` : base;
}
```

```ts
import * as THREE from 'three';

export interface SceneState {
  busy: boolean;
  contextFill: number;
  attention: boolean;
  motion: 'full' | 'reduced' | 'off';
}

const CYAN = new THREE.Color('#52d8ff');
const VIOLET = new THREE.Color('#8b6cff');
const MAGENTA = new THREE.Color('#ff4fd8');
const AMBER = new THREE.Color('#ffb547');

function contextArc(fill: number): THREE.Mesh {
  const len = Math.max(0.0001, Math.PI * 2 * fill);
  const geo = new THREE.RingGeometry(1.42, 1.5, 128, 1, Math.PI / 2, len);
  const mat = new THREE.MeshBasicMaterial({
    color: fill > 0.8 ? AMBER : CYAN, transparent: true, opacity: 0.9,
    side: THREE.DoubleSide, blending: THREE.AdditiveBlending, depthWrite: false,
  });
  const mesh = new THREE.Mesh(geo, mat);
  mesh.rotation.x = -Math.PI / 2;
  mesh.position.y = 0.01;
  return mesh;
}

// mountConstellation draws the holographic projector: a wireframe core
// hovering over concentric light rings, a context-window arc on the
// platform, and a hex lattice fading into fog. It only renders while
// something moves, and stops when the tab is hidden.
export function mountConstellation(canvas: HTMLCanvasElement, initial: SceneState) {
  let state = initial;
  const renderer = new THREE.WebGLRenderer({ canvas, antialias: true, alpha: true });
  renderer.setPixelRatio(Math.min(window.devicePixelRatio, 2));
  const scene = new THREE.Scene();
  scene.fog = new THREE.FogExp2(0x060a1a, 0.09);
  const camera = new THREE.PerspectiveCamera(42, 1, 0.1, 100);
  camera.position.set(0, 2.4, 7.2);
  camera.lookAt(0, 0.8, 0);

  const coreMat = new THREE.MeshBasicMaterial({ color: CYAN.clone(), wireframe: true, transparent: true, opacity: 0.85 });
  const core = new THREE.Mesh(new THREE.IcosahedronGeometry(0.7, 1), coreMat);
  core.position.y = 1.15;
  const glowMat = new THREE.MeshBasicMaterial({ color: CYAN.clone(), transparent: true, opacity: 0.22, blending: THREE.AdditiveBlending, depthWrite: false });
  const glow = new THREE.Mesh(new THREE.SphereGeometry(0.42, 32, 32), glowMat);
  core.add(glow);
  scene.add(core);

  const rings = new THREE.Group();
  [1.1, 1.75, 2.45].forEach((r, i) => {
    const m = new THREE.Mesh(
      new THREE.RingGeometry(r, r + 0.025 + i * 0.01, 160),
      new THREE.MeshBasicMaterial({ color: i === 1 ? VIOLET : CYAN, transparent: true, opacity: 0.6 - i * 0.15, side: THREE.DoubleSide, blending: THREE.AdditiveBlending, depthWrite: false }),
    );
    m.rotation.x = -Math.PI / 2;
    rings.add(m);
  });
  scene.add(rings);

  const beam = new THREE.Mesh(
    new THREE.CylinderGeometry(0.45, 1.15, 1.1, 48, 1, true),
    new THREE.MeshBasicMaterial({ color: CYAN, transparent: true, opacity: 0.07, side: THREE.DoubleSide, blending: THREE.AdditiveBlending, depthWrite: false }),
  );
  beam.position.y = 0.55;
  scene.add(beam);

  const lattice = new THREE.Group();
  const hexEdges = new THREE.EdgesGeometry(new THREE.CircleGeometry(0.14, 6));
  for (let i = 0; i < 42; i++) {
    const line = new THREE.LineSegments(hexEdges, new THREE.LineBasicMaterial({ color: i % 5 === 0 ? VIOLET : CYAN, transparent: true, opacity: 0.28 }));
    const theta = (i / 42) * Math.PI * 2;
    const r = 3.1 + (i % 3) * 0.45;
    line.position.set(Math.cos(theta) * r, 0.4 + ((i * 37) % 23) / 10, Math.sin(theta) * r);
    line.lookAt(0, line.position.y, 0);
    lattice.add(line);
  }
  scene.add(lattice);

  let arc = contextArc(state.contextFill);
  scene.add(arc);

  const resize = () => {
    const { clientWidth: w, clientHeight: h } = canvas;
    if (!w || !h) return;
    renderer.setSize(w, h, false);
    camera.aspect = w / h;
    camera.updateProjectionMatrix();
    kick();
  };
  const ro = new ResizeObserver(resize);
  ro.observe(canvas);

  let raf = 0;
  let last = performance.now();
  // Reduced motion renders single frames on each update, so state changes
  // (attention color, context arc) still show without continuous motion.
  const animating = () => !document.hidden && state.motion === 'full';

  function draw(now: number) {
    const dt = Math.min(0.05, (now - last) / 1000);
    last = now;
    if (state.motion !== 'off') {
      const speed = state.busy ? 0.9 : 0.22;
      core.rotation.y += dt * speed;
      core.rotation.x += dt * speed * 0.3;
      rings.rotation.y -= dt * 0.08;
      lattice.rotation.y += dt * 0.02;
      const pulse = state.busy ? 1 + Math.sin(now / 180) * 0.08 : 1;
      glow.scale.setScalar(pulse);
    }
    const target = state.attention ? MAGENTA : CYAN;
    coreMat.color.lerp(target, 0.2);
    glowMat.color.lerp(target, 0.2);
    renderer.render(scene, camera);
    raf = animating() ? requestAnimationFrame(draw) : 0;
  }

  function kick() {
    if (!raf) raf = requestAnimationFrame((t) => { last = t; draw(t); });
  }

  const onVisibility = () => kick();
  document.addEventListener('visibilitychange', onVisibility);
  resize();

  return {
    update(next: SceneState) {
      if (next.contextFill !== state.contextFill) {
        scene.remove(arc);
        arc.geometry.dispose();
        (arc.material as THREE.Material).dispose();
        arc = contextArc(next.contextFill);
        scene.add(arc);
      }
      state = next;
      kick();
    },
    dispose() {
      cancelAnimationFrame(raf);
      ro.disconnect();
      document.removeEventListener('visibilitychange', onVisibility);
      renderer.dispose();
    },
  };
}
```

```tsx
import { useEffect, useRef, useState } from 'preact/hooks';
import { state } from '../../state/store';
import { contextFill } from '../../state/reducer';
import { lowPower, motion } from '../../state/motion';
import type { SceneState } from '../../scene/constellation';
import { ConstellationSvg } from './ConstellationSvg';

function webglAvailable(): boolean {
  try {
    return !!document.createElement('canvas').getContext('webgl2');
  } catch {
    return false;
  }
}

type Scene = { update(s: SceneState): void; dispose(): void };

export function Stage() {
  const s = state.value;
  const fill = contextFill(s);
  const attention = s.permissions.length > 0 || s.question !== null;
  const use3D = !lowPower.value && webglAvailable();
  const canvas = useRef<HTMLCanvasElement>(null);
  const scene = useRef<Scene | null>(null);
  const [failed, setFailed] = useState(false);
  const sceneState: SceneState = { busy: s.busy, contextFill: fill, attention, motion: motion.value };

  useEffect(() => {
    if (!use3D || failed || !canvas.current) return;
    let disposed = false;
    import('../../scene/constellation')
      .then(({ mountConstellation }) => {
        if (disposed || !canvas.current) return;
        scene.current = mountConstellation(canvas.current, sceneState);
      })
      .catch(() => setFailed(true));
    return () => {
      disposed = true;
      scene.current?.dispose();
      scene.current = null;
    };
  }, [use3D, failed]);

  useEffect(() => {
    scene.current?.update(sceneState);
  }, [s.busy, fill, attention, motion.value]);

  const status = attention ? 'Waiting for you' : s.busy ? 'Working' : 'Idle';
  return (
    <div class="stage__inner">
      {use3D && !failed
        ? <canvas ref={canvas} class="stage__canvas" aria-hidden="true" />
        : <ConstellationSvg fill={fill} busy={s.busy} attention={attention} />}
      <ul class="agent-list" aria-label="Agents">
        <li data-status={attention ? 'attention' : s.busy ? 'running' : 'idle'}>
          <span class="agent-list__glyph" aria-hidden="true">⬡</span>
          <span>Coder</span>
          <span class="hud-label">{status}</span>
        </li>
      </ul>
    </div>
  );
}
```

```ts
const KEYS = ['command', 'file_path', 'path', 'pattern', 'url', 'query', 'prompt', 'description'];
const MAX = 120;

export function summarizeTool(_name: string, input: string): string {
  let parsed: Record<string, unknown>;
  try {
    parsed = JSON.parse(input);
  } catch {
    return '';
  }
  for (const k of KEYS) {
    const v = parsed[k];
    if (typeof v === 'string' && v) return v.length > MAX ? `${v.slice(0, MAX)}…` : v;
  }
  return '';
}
```

```ts
export function activeMention(text: string, caret: number): { start: number; query: string } | null {
  const before = text.slice(0, caret);
  const m = /(^|\s)@([^\s@]*)$/.exec(before);
  if (!m) return null;
  return { start: caret - m[2].length - 1, query: m[2] };
}

export function applyMention(text: string, start: number, caret: number, path: string) {
  const insert = `@${path} `;
  const rest = text.slice(caret).replace(/^\s/, '');
  return { text: text.slice(0, start) + insert + rest, caret: start + insert.length };
}
```

```tsx
import { useEffect, useRef, useState } from 'preact/hooks';

import { api } from '../../api/http';
import { activeMention, applyMention } from './mention';

export function CommandDeck() {
  const s = state.value;
  const [text, setText] = useState('');
  const [files, setFiles] = useState<File[]>([]);
  const [error, setError] = useState('');
  const [sending, setSending] = useState(false);
  const [suggest, setSuggest] = useState<{ start: number; items: string[]; index: number } | null>(null);
  const area = useRef<HTMLTextAreaElement>(null);
  const picker = useRef<HTMLInputElement>(null);
  const ended = s.conn === 'ended';

  useEffect(() => {
    const el = area.current;
    if (!el) return;
    const m = activeMention(text, el.selectionStart);
    if (!m) { setSuggest(null); return; }
    const t = window.setTimeout(async () => {
      try {
        const { files: items } = await api.completeFiles(m.query);
        setSuggest(items.length ? { start: m.start, items, index: 0 } : null);
      } catch {
        setSuggest(null);
      }
    }, 120);
    return () => window.clearTimeout(t);
  }, [text]);

  const addFiles = (list: FileList | File[] | null) => {
    if (!list) return;
    setFiles((cur) => [...cur, ...Array.from(list)]);
  };

  const pick = (path: string) => {
    const el = area.current!;
    const next = applyMention(text, suggest!.start, el.selectionStart, path);
    setText(next.text);
    setSuggest(null);
    requestAnimationFrame(() => { el.focus(); el.setSelectionRange(next.caret, next.caret); });

    if (!text.trim()) { setError('Type a task before transmitting.'); return; }

      if (e.key === 'ArrowDown' || e.key === 'ArrowUp') {
        e.preventDefault();

        setSuggest({ ...suggest, index: (suggest.index + d + suggest.items.length) % suggest.items.length });

      if (e.key === 'Escape') { e.preventDefault(); setSuggest(null); return; }

              {f.name}

        <textarea
          id="deck-input"
          ref={area}
          rows={2}
          value={text}
```

```ts
import type { Question, QuestionAnswer } from '../../api/types';

export type Draft = { selected?: string[]; text?: string; yes?: boolean };

export function isComplete(q: Question, d?: Draft): boolean {
  if (!d) return false;
  if (d.text && d.text.trim()) return true;
  switch (q.type) {
    case 'yes_no': return d.yes !== undefined;
    case 'single_choice':
    case 'multi_choice': return (d.selected?.length ?? 0) > 0;
    case 'free_text': return false;
  }
}

export function buildAnswers(questions: Question[], draft: Record<string, Draft>): QuestionAnswer[] {
  return questions.map((q) => {
    const d = draft[q.id] ?? {};
    const a: QuestionAnswer = { question_id: q.id };
    if (q.type === 'yes_no' && d.yes !== undefined) a.yes = d.yes;
    if ((q.type === 'single_choice' || q.type === 'multi_choice') && d.selected?.length) a.selected_ids = d.selected;
    if (d.text && d.text.trim()) a.fill_in_text = d.text.trim();
    return a;
  });
}
```

```tsx
import { useEffect, useRef, useState } from 'preact/hooks';
import type { Question, QuestionRequest } from '../../api/types';
import { actions } from '../../state/store';
import { buildAnswers, isComplete, type Draft } from './answers';

function Field({ q, d, onChange }: { q: Question; d: Draft; onChange: (d: Draft) => void }) {
  const name = `q-${q.id}`;
  return (
    <fieldset class="qform__field">
      <legend class="interrupt__title">{q.question}</legend>
      {q.description && <p class="qform__desc">{q.description}</p>}
      {q.type === 'yes_no' && (
        <div class="qform__choices">
          {[true, false].map((v) => (
            <label key={String(v)} class="qform__choice">
              <input type="radio" name={name} checked={d.yes === v} onChange={() => onChange({ ...d, yes: v })} />
              {v ? 'Yes' : 'No'}
            </label>
          ))}
        </div>
      )}
      {(q.type === 'single_choice' || q.type === 'multi_choice') && (
        <div class="qform__choices">
          {q.choices?.map((c) => {
            const checked = d.selected?.includes(c.id) ?? false;
            const multi = q.type === 'multi_choice';
            return (
              <label key={c.id} class="qform__choice">
                <input
                  type={multi ? 'checkbox' : 'radio'}
                  name={name}
                  checked={checked}
                  onChange={() => onChange({
                    ...d,
                    selected: multi ? (checked ? d.selected!.filter((x) => x !== c.id) : [...(d.selected ?? []), c.id]) : [c.id],
                  })}
                />
                <span><strong>{c.label}</strong>{c.description && <span class="qform__desc"> {c.description}</span>}</span>
              </label>
            );
          })}
        </div>
      )}
      <label class="qform__text">
        <span class="hud-label">{q.type === 'free_text' ? 'Answer' : 'Or write your own'}</span>
        <textarea rows={2} value={d.text ?? ''} onInput={(e) => onChange({ ...d, text: (e.currentTarget as HTMLTextAreaElement).value })} />
      </label>
    </fieldset>
  );
}

export function QuestionForm({ req }: { req: QuestionRequest }) {
  const [tab, setTab] = useState(0);
  const [draft, setDraft] = useState<Record<string, Draft>>({});
  const [error, setError] = useState('');
  const root = useRef<HTMLFormElement>(null);
  const multi = req.questions.length > 1;
  const confirmTab = multi ? req.questions.length : -1;
  useEffect(() => { root.current?.querySelector<HTMLElement>('input, textarea, button')?.focus(); }, [req.id, tab]);

  const submit = () => {
    const missing = req.questions.findIndex((q) => !isComplete(q, draft[q.id]));
    if (missing >= 0) {
      setTab(missing);
      setError(`Answer "${req.questions[missing].question}" before sending.`);
      return;
    }
    void actions.answer(req.id, buildAnswers(req.questions, draft));
  };

  return (
    <form ref={root} class="interrupt qform" role="dialog" aria-modal="true" aria-labelledby="q-title" onSubmit={(e) => { e.preventDefault(); submit(); }}>
      <p id="q-title" class="hud-label">The agent is asking</p>
      {multi && (
        <div class="qform__tabs" role="tablist">
          {req.questions.map((q, i) => (
            <button key={q.id} type="button" role="tab" aria-selected={tab === i} data-done={isComplete(q, draft[q.id])} onClick={() => setTab(i)}>
              {q.label || `Q${i + 1}`}
            </button>
          ))}
          <button type="button" role="tab" aria-selected={tab === confirmTab} onClick={() => setTab(confirmTab)}>Confirm</button>
        </div>
      )}
      {tab === confirmTab ? (
        <section class="qform__confirm">
          <h2 class="interrupt__title">{req.confirm_title || 'Send these answers?'}</h2>
          {req.confirm_description && <p>{req.confirm_description}</p>}
        </section>
      ) : (
        <Field q={req.questions[tab]} d={draft[req.questions[tab].id] ?? {}} onChange={(d) => setDraft({ ...draft, [req.questions[tab].id]: d })} />
      )}
      <p class="deck__error" role="alert">{error}</p>
      <div class="interrupt__actions">
        {multi && tab !== confirmTab
          ? <button type="button" class="btn btn--primary" onClick={() => setTab(tab + 1)}>Next</button>
          : <button type="submit" class="btn btn--primary">Send answers</button>}
        <button type="button" class="btn btn--ghost" onClick={() => void actions.cancelQuestion(req.id)}>Skip question</button>
      </div>
    </form>
  );
}
```

```ts
import { test as base } from '@playwright/test';
import { spawn, type ChildProcess } from 'node:child_process';
import { fileURLToPath } from 'node:url';
import readline from 'node:readline';

const repoRoot = fileURLToPath(new URL('../..', import.meta.url));

export const test = base.extend<{}, { gateway: { launch: string; origin: string } }>({
  gateway: [async ({}, use) => {
    const proc: ChildProcess = spawn('go', ['run', './internal/web/cmd/webfake'], { cwd: repoRoot, stdio: ['ignore', 'pipe', 'inherit'] });
    const rl = readline.createInterface({ input: proc.stdout! });
    const launch = await new Promise<string>((resolve, reject) => {
      const timer = setTimeout(() => reject(new Error('webfake did not print a URL')), 60_000);
      rl.once('line', (l) => { clearTimeout(timer); resolve(l.trim()); });
    });
    await use({ launch, origin: launch.split('/#')[0] });
    proc.kill('SIGTERM');
  }, { scope: 'worker' }],
});

export { expect } from '@playwright/test';
```
