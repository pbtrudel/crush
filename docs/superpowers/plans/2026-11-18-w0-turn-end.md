# Turn End Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Record in the session log why each run of the agent loop ended (delivery item 2 of the measurement design), using the spec's precedence rules when more than one reason applies.

**Architecture:** The message package gains a typed `TurnEnd` value, a `turn_end` field on the finish part and a `SetTurnEnd` setter. A new file `internal/agent/turn_end.go` holds three pure functions that implement the precedence: one for a run whose step loop returned an error, one for a run that ended without one (from the facts of its last step), and one that applies the two compaction rules. `Run` calls them at its exits and writes the value on the finish part of the run's last step; the canceled-turn marker gets `canceled`.

**Tech Stack:** Go 1.27, `charm.land/fantasy` v0.45.5, testify `require`.

**Spec:** `docs/superpowers/specs/2026-11-17-measurement-design.md`, section 1.2 (Turn end), Failure behavior, Validation, Delivery item 2. PR 1 (build stamp and compaction trigger) is merged as `28b5513d`.

## Global Constraints

- Work in a fresh worktree created from `origin/main` after `git fetch origin` (for example `worktree create` with name `w0-turn-end`, base `origin/main`). Paths below are relative to its root.
- `turn_end` is on the finish part of the last step of each run, JSON `turn_end,omitempty`. A compaction summary never carries it. The step's own `reason` field is unchanged. It is never sent to a provider.
- Values in this pull request, exactly: `completed`, `empty`, `max_tokens`, `content_filter`, `tool_stop`, `loop_guard`, `repetition_guard`, `context_guard`, `context_overflow`, `compaction_blocked`, `compaction_failed`, `canceled`, `request_timeout`, `provider_error`, `error`.
- `step_limit` and `time_limit` are not added here. They come with `--max-steps` and `--timeout` (delivery item 6), which adds them at their spec positions: `time_limit` first in tier 1, `step_limit` last in tier 3.
- Precedence, first match wins (spec 1.2):
  1. The step loop returned an error: `repetition_guard`, `canceled`, `request_timeout`, `context_overflow`, `provider_error`, `error`.
  2. The last step called no tools: `max_tokens`, `content_filter`, `empty`, `completed`.
  3. The last step called tools: `context_guard`, `tool_stop`, `loop_guard`. When none applies (the provider ended a step that called tools), the step's finish decides: `max_tokens`, `content_filter`, otherwise `completed`.
  Then: a required compaction (after `context_guard` or `context_overflow`) that a hook blocks gives `compaction_blocked`; one that fails gives `compaction_failed`. A compaction after any other ending changes nothing.
- `empty` means the last step had no non-whitespace text and no tool call (reasoning alone is empty).
- Writing the stamp never fails a turn: a failed write is logged with `slog.Warn` and the run continues. The existing error-path write keeps its current behavior.
- Runs with no assistant message (an error before the first step was created, other than a cancel) carry no stamp.
- Do not change the existing behavior around a blocked compaction (it still requeues the prompt); the spec lists that under "Noticed, not changed here".
- Style: gofumpt; comments on their own line start with a capital, end with a period, wrap at 78 columns; no em dashes; testify `require`; log messages start with a capital letter.
- Size: estimate about 480 changed lines, mostly tests. The classifier and its wiring are one concern, so this stays one pull request; the PR description states the size.
- Commits: one per task, semantic subjects. Run commit steps only when the user has authorized commits for this work; otherwise stop at the staged diff.

## Review Focus

1. Two flags with the same type side by side: the last-step facts are passed as a struct with named fields, not as positional booleans, because PR 1 showed that swapped boolean arguments go unnoticed. Pinned by the table tests in Task 2 and the guard and overflow runs in Task 3.
2. A required compaction that a hook blocks: today it still requeues the prompt, so the first run must read `compaction_blocked` and its continuation `completed`. Pinned in Task 3.
3. A compaction after a completed turn that fails: `Run` returns the error, but the run's stamp stays `completed`. Pinned in Task 3.
4. Summaries: the summary message written inside a run must never carry `turn_end`. Pinned in Task 3.
5. The repetition detector stops a run by cancelling it, so a repetition stop must not read `canceled`. Pinned in Task 2 (an error that is both) and Task 3 (a run).

// TurnEnd names why a run of the agent loop ended. The values and the order
// in which they win when several apply are defined in the measurement
// design (docs/superpowers/specs/2026-11-17-measurement-design.md, 1.2).
type TurnEnd string

const (
	// The model stopped calling tools.
	TurnEndCompleted TurnEnd = "completed"
	// The last step had neither text nor a tool call.
	TurnEndEmpty TurnEnd = "empty"
	// The last step was cut at the output limit.
	TurnEndMaxTokens TurnEnd = "max_tokens"
	// The provider refused to continue.
	TurnEndContentFilter TurnEnd = "content_filter"
	// A tool result halted the turn: a denied permission, a hook halt, a
	// cancelled question.
	TurnEndToolStop TurnEnd = "tool_stop"
	// The same tool call kept repeating.
	TurnEndLoopGuard TurnEnd = "loop_guard"
	// The output kept repeating.
	TurnEndRepetitionGuard TurnEnd = "repetition_guard"
	// The context was nearly full; the run is compacted and continued.
	TurnEndContextGuard TurnEnd = "context_guard"
	// The provider rejected the request as too long.
	TurnEndContextOverflow TurnEnd = "context_overflow"
	// A hook blocked the compaction the run required.
	TurnEndCompactionBlocked TurnEnd = "compaction_blocked"
	// The compaction the run required failed.
	TurnEndCompactionFailed TurnEnd = "compaction_failed"
	// The user or a caller cancelled.
	TurnEndCanceled TurnEnd = "canceled"
	// Crush's own request or stream timeout fired.
	TurnEndRequestTimeout TurnEnd = "request_timeout"
	// The provider or the network failed after retries.
	TurnEndProviderError TurnEnd = "provider_error"
	// Anything else.
	TurnEndError TurnEnd = "error"
)
```

func (m *Message) SetTurnEnd(end TurnEnd) {
	for i, part := range m.Parts {
		finish, ok := part.(Finish)
		if !ok {
			continue
		}
		finish.TurnEnd = end
		m.Parts[i] = finish
		return
	}
}

package agent

import (
	"context"
	"errors"
	"strings"

	"charm.land/fantasy"
	"github.com/charmbracelet/crush/internal/message"
)

// stepEnding is what the turn-end rules need to know about the last step
// of a run that ended without an error. The fields are named, not
// positional, because two booleans passed in the wrong order would go
// unnoticed.
type stepEnding struct {
	finish       message.FinishReason
	hasText      bool
	hasToolCalls bool
	guardTripped bool
	toolStopped  bool
	loopRepeated bool
}

// turnEndForError decides how a run ended when its step loop returned an
// error. The order matters: the repetition detector stops a run by
// cancelling it, so it is tested before the cancel.
func turnEndForError(err error) message.TurnEnd {
	var timeoutErr *requestTimeoutError
	var providerErr *fantasy.ProviderError
	var fantasyErr *fantasy.Error
	switch {
	case errors.Is(err, errRepetitionDetected):
		return message.TurnEndRepetitionGuard
	case errors.Is(err, context.Canceled):
		return message.TurnEndCanceled
	case errors.As(err, &timeoutErr):
		return message.TurnEndRequestTimeout
	case isContextOverflowError(err):
		return message.TurnEndContextOverflow
	case errors.As(err, &providerErr), errors.As(err, &fantasyErr), fantasy.IsTransportError(err):
		return message.TurnEndProviderError
	default:
		return message.TurnEndError
	}
}

// turnEndForStep decides how a run ended without an error, from its last
// step. A step that called no tools means the model had stopped, whatever
// limit was reached on the same step. A step that called tools means
// something stopped the loop.
func turnEndForStep(step stepEnding) message.TurnEnd {
	if !step.hasToolCalls {
		switch {
		case step.finish == message.FinishReasonMaxTokens:
			return message.TurnEndMaxTokens
		case step.finish == message.FinishReasonContentFilter:
			return message.TurnEndContentFilter
		case !step.hasText:
			return message.TurnEndEmpty
		default:
			return message.TurnEndCompleted
		}
	}
	switch {
	case step.guardTripped:
		return message.TurnEndContextGuard
	case step.toolStopped:
		return message.TurnEndToolStop
	case step.loopRepeated:
		return message.TurnEndLoopGuard
	case step.finish == message.FinishReasonMaxTokens:
		return message.TurnEndMaxTokens
	case step.finish == message.FinishReasonContentFilter:
		return message.TurnEndContentFilter
	default:
		// The provider ended a step that called tools, and no guard
		// stopped the loop, so the model is taken at its word.
		return message.TurnEndCompleted
	}
}

// turnEndAfterCompaction applies the rules that follow the precedence:
// only a compaction the run required changes how the run ended.
func turnEndAfterCompaction(end message.TurnEnd, summarizeErr error) message.TurnEnd {
	if end != message.TurnEndContextGuard && end != message.TurnEndContextOverflow {
		return end
	}
	switch {
	case errors.Is(summarizeErr, ErrCompactionBlocked):
		return message.TurnEndCompactionBlocked
	case summarizeErr != nil:
		return message.TurnEndCompactionFailed
	default:
		return end
	}
}

// lastStepEnding gathers the facts turnEndForStep needs from the run's
// last assistant message and the steps the loop completed. guardTripped
// is the mid-turn context guard's flag.
func lastStepEnding(msg *message.Message, steps []fantasy.StepResult, guardTripped bool) stepEnding {
	ending := stepEnding{
		finish:       msg.FinishReason(),
		hasText:      strings.TrimSpace(msg.Content().Text) != "",
		hasToolCalls: len(msg.ToolCalls()) > 0,
		guardTripped: guardTripped,
		loopRepeated: hasRepeatedToolCalls(steps, loopDetectionWindowSize, loopDetectionMaxRepeats),
	}
	if len(steps) > 0 {
		for _, result := range steps[len(steps)-1].Content.ToolResults() {
			if result.StopTurn {
				ending.toolStopped = true
				break
			}
		}
	}
	return ending
}
```

package agent

import (
	"context"
	"errors"
	"strings"
	"sync"
	"testing"
	"time"

	"charm.land/fantasy"
	"github.com/charmbracelet/crush/internal/config"
	"github.com/charmbracelet/crush/internal/hooks"
	"github.com/charmbracelet/crush/internal/message"
	"github.com/stretchr/testify/require"
)

// scriptedCall is one scripted model answer: stream parts, or an error
// returned instead of a stream.
type scriptedCall struct {
	parts []fantasy.StreamPart
	err   error
}

// scriptedModel answers the agent's calls in order and repeats the last
// answer once the script runs out. Calls without tools (title generation)
// get a plain answer and do not use up the script; agent steps and
// compactions both carry the session's tools.
type scriptedModel struct {
	finishStreamModel
	mu     sync.Mutex
	script []scriptedCall
	calls  int
}

func (m *scriptedModel) Stream(_ context.Context, call fantasy.Call) (fantasy.StreamResponse, error) {
	if len(call.Tools) == 0 {
		return replayStreamParts(fusionTextParts("Title")), nil
	}
	m.mu.Lock()
	next := m.script[min(m.calls, len(m.script)-1)]
	m.calls++
	m.mu.Unlock()
	if next.err != nil {
		return nil, next.err
	}
	return replayStreamParts(next.parts), nil
}

func answer(text string, finish fantasy.FinishReason, inputTokens int64) scriptedCall {
	parts := []fantasy.StreamPart{}
	if text != "" {
		parts = append(parts,
			fantasy.StreamPart{Type: fantasy.StreamPartTypeTextStart, ID: "text"},
			fantasy.StreamPart{Type: fantasy.StreamPartTypeTextDelta, ID: "text", Delta: text},
			fantasy.StreamPart{Type: fantasy.StreamPartTypeTextEnd, ID: "text"},
		)
	}
	parts = append(parts, fantasy.StreamPart{
		Type:         fantasy.StreamPartTypeFinish,
		FinishReason: finish,
		Usage:        fantasy.Usage{InputTokens: inputTokens, OutputTokens: 10, TotalTokens: inputTokens + 10},
	})
	return scriptedCall{parts: parts}
}

func callTool(name string, inputTokens int64) scriptedCall {
	return scriptedCall{parts: []fantasy.StreamPart{
		{Type: fantasy.StreamPartTypeToolCall, ID: "call-1", ToolCallName: name, ToolCallInput: "{}"},
		{
			Type:         fantasy.StreamPartTypeFinish,
			FinishReason: fantasy.FinishReasonToolCalls,
			Usage:        fantasy.Usage{InputTokens: inputTokens, OutputTokens: 10, TotalTokens: inputTokens + 10},
		},
	}}
}

// turnEnds lists the turn_end of every assistant message that has one, in
// order, and checks that no compaction summary carries one.
func turnEnds(t *testing.T, env fakeEnv, sessionID string) []message.TurnEnd {
	t.Helper()
	msgs, err := env.messages.List(t.Context(), sessionID)
	require.NoError(t, err)
	var ends []message.TurnEnd
	for _, msg := range msgs {
		finish := msg.FinishPart()
		if msg.Role != message.Assistant || finish == nil {
			continue
		}
		if msg.IsSummaryMessage {
			require.Empty(t, finish.TurnEnd, "a compaction summary never carries turn_end")
			continue
		}
		if finish.TurnEnd != "" {
			ends = append(ends, finish.TurnEnd)
		}
	}
	return ends
}

// Window 200,000 tokens: the mid-turn guard trips when 40,000 or fewer
// remain, and the threshold compacts a finished turn at 100,000.
func TestTurnEnd_Runs(t *testing.T) {
	const (
		small    = 1_000
		atGuard  = 190_000
		overHalf = 150_000
	)
	blockCompaction := map[string][]config.HookConfig{
		hooks.EventPreCompact: {{Command: `echo "not now" >&2; exit 2`}},
	}
	summary := answer("# Conversation Summary\n\nAll good.", fantasy.FinishReasonStop, small)
	tests := []struct {
		name        string
		script      []scriptedCall
		tool        fantasy.AgentTool
		hooks       map[string][]config.HookConfig
		wantErr     bool
		want        []message.TurnEnd
		wantTrigger string
	}{
		{name: "completed", script: []scriptedCall{answer("done", fantasy.FinishReasonStop, small)}, want: []message.TurnEnd{message.TurnEndCompleted}},
		{name: "empty", script: []scriptedCall{answer("", fantasy.FinishReasonStop, small)}, want: []message.TurnEnd{message.TurnEndEmpty}},
		{name: "max tokens", script: []scriptedCall{answer("partial", fantasy.FinishReasonLength, small)}, want: []message.TurnEnd{message.TurnEndMaxTokens}},
		{name: "content filter", script: []scriptedCall{answer("", fantasy.FinishReasonContentFilter, small)}, want: []message.TurnEnd{message.TurnEndContentFilter}},
		{name: "repetition", script: []scriptedCall{answer(strings.Repeat("a", 600), fantasy.FinishReasonStop, small)}, wantErr: true, want: []message.TurnEnd{message.TurnEndRepetitionGuard}},
		{name: "canceled", script: []scriptedCall{failWith(context.Canceled)}, wantErr: true, want: []message.TurnEnd{message.TurnEndCanceled}},
		{name: "request timeout", script: []scriptedCall{failWith(&requestTimeoutError{timeout: time.Second, cause: context.DeadlineExceeded})}, wantErr: true, want: []message.TurnEnd{message.TurnEndRequestTimeout}},
		{name: "provider error", script: []scriptedCall{failWith(&fantasy.ProviderError{StatusCode: 400, Message: "bad request"})}, wantErr: true, want: []message.TurnEnd{message.TurnEndProviderError}},
		{name: "other error", script: []scriptedCall{failWith(errors.New("boom"))}, wantErr: true, want: []message.TurnEnd{message.TurnEndError}},
		{name: "tool stop", script: []scriptedCall{callTool("halt", small)}, tool: &haltTool{recordingTool{name: "halt"}}, want: []message.TurnEnd{message.TurnEndToolStop}},
		{
			name:        "context guard, then the continuation completes",
			script:      []scriptedCall{callTool("alpha", atGuard), summary, answer("done", fantasy.FinishReasonStop, small)},
			want:        []message.TurnEnd{message.TurnEndContextGuard, message.TurnEndCompleted},
			wantTrigger: "guard",
		},
		{
			name:        "context overflow, then the continuation completes",
			script:      []scriptedCall{failWith(&fantasy.ProviderError{StatusCode: 400, ContextTooLargeErr: true}), summary, answer("done", fantasy.FinishReasonStop, small)},
			want:        []message.TurnEnd{message.TurnEndContextOverflow, message.TurnEndCompleted},
			wantTrigger: "overflow",
		},
		{
			// A blocked compaction still requeues the prompt today; the
			// continuation starts from a small context and completes.
			name:   "required compaction blocked",
			script: []scriptedCall{callTool("alpha", atGuard), answer("done", fantasy.FinishReasonStop, small)},
			hooks:  blockCompaction,
			want:   []message.TurnEnd{message.TurnEndCompactionBlocked, message.TurnEndCompleted},
		},
		{
			name:    "required compaction failed",
			script:  []scriptedCall{callTool("alpha", atGuard), failWith(errors.New("summary failed"))},
			wantErr: true,
			want:    []message.TurnEnd{message.TurnEndCompactionFailed},
		},
		{
			// The model finished; the compaction afterwards fails and Run
			// reports it, but the run's ending is unchanged.
			name:    "compaction after a completed turn failed",
			script:  []scriptedCall{answer("done", fantasy.FinishReasonStop, overHalf), failWith(errors.New("summary failed"))},
			wantErr: true,
			want:    []message.TurnEnd{message.TurnEndCompleted},
		},
	}
	for _, tt := range tests {
		t.Run(tt.name, func(t *testing.T) {
			env := testEnv(t)
			tool := tt.tool
			if tool == nil {
				tool = &recordingTool{name: "alpha"}
			}
			agent := newCompactionAgent(env, &scriptedModel{script: tt.script}, nil, false, tool)
			if tt.hooks != nil {
				dir := t.TempDir()
				agent.hooks = hooks.NewRunner(hooks.Static(tt.hooks), dir, dir)
			}
			sess, err := env.sessions.Create(t.Context(), tt.name)
			require.NoError(t, err)

			_, err = agent.Run(t.Context(), SessionAgentCall{SessionID: sess.ID, Prompt: "go"})
			if tt.wantErr {
				require.Error(t, err)
			} else {
				require.NoError(t, err)
			}

			require.Equal(t, tt.want, turnEnds(t, env, sess.ID))
			if tt.wantTrigger != "" {
				require.Equal(t, tt.wantTrigger, summaryTrigger(t, env, sess.ID))
			}
		})
	}
}
