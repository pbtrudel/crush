Launch a new agent that has access to a restricted set of tools. By default it uses the read-only task preset. Set `agent` to a configured preset to give the subagent that preset's tools, MCP servers, and context paths. When you are searching for a keyword or file and are not confident that you will find the right match on the first try, use the agent tool to perform the search for you.

By default the agent runs in the background: the tool returns a subagent id immediately and a completion notice arrives when it finishes. Start independent delegations together and continue useful work while they run. When only waiting for their results remains, end your turn instead of sleeping or polling; use subagent_output with wait=true only when you are genuinely blocked.
