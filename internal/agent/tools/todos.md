Manage a structured task list for multi-step work; each task has pending/in_progress/completed state.

Use this tool to plan multi-step work and to report progress. Keep exactly one task in_progress at a time.

Update the list immediately after each task is implemented, in the same turn the work finishes: mark the finished task completed and the next task in_progress in a single call. Never leave a finished task pending or in_progress, and never end your turn with work that is actually done still marked open. Before writing your final response, reconcile the list so it matches reality.

Skip this tool for simple or single-step tasks.

A final answer that reports work as complete while the list still shows it unfinished is reported to the user as a stale list, so keep the two in step.
