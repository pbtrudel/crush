Search the tools this session holds back, and reveal the ones you need.

Lazy tool mode sends only a small core palette on every request to keep the tool-schema cost down: read/view, edit, write, multiedit, bash, grep, glob, ls, todos, worktree, job_output, job_kill, question, the delegation tools, and this one. Every other tool exists and works, but its schema is not sent until you reveal it here.

Give a tool name when you know it, or words that describe what you want to do ("language server references", "fetch a URL", "open a GitHub issue"). Phrases work: the words are matched one by one, and a tool whose name or description covers them all is a match.

The reply lists up to three matches with their full parameter schemas, and those tools are callable from your next step for the rest of the session. When more tools match than the reply shows, narrow the query or ask for one by name. A tool you have not revealed cannot be called: the request is rejected as an unknown tool. Search once for each tool you need, then use it directly.
